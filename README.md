# Fitness Trainer & Client Management System — ER Diagram

## 📌 Project Overview

This project presents the database design for a **Fitness Trainer & Client Management System**.

The system is designed to manage clients, trainers, fitness plans, plan enrollments, payments, consultations, workout activity, weekly progress check-ins, and trainer feedback.

The primary objective of this project is to design a practical and normalized **Entity-Relationship (ER) diagram** that represents the major entities and relationships required by the business.

---

## 🎯 System Requirements

The database design supports the following requirements:

* Manage clients and trainers
* Maintain user profiles and authentication-related information
* Create and manage fitness plans
* Allow clients to purchase multiple fitness plans over time
* Allow multiple clients to enroll in the same fitness plan
* Assign trainers to client plans
* Track remaining workout days
* Manage payments and transaction information
* Track daily workout/activity records
* Schedule trainer-client consultations
* Record weekly client progress check-ins
* Store progress images and notes
* Allow trainers to provide feedback on client check-ins
